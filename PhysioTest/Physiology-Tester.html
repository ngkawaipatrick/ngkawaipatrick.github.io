HTI5001 · Process tester v2

Four process types: Pathway and Sequence = order + names only (Blanks mode). Feedback loop = one template; Blanks mode asks receptor / control centre / effector. Cause→consequence and Mechanism chain = ↑↓ Direction and Because→so modes. Spelling is checked loosely; scores are stored on this device only. Keys: Enter = check, R = retry, N/P = next/previous, A = reveal.
